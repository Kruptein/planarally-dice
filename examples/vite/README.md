# Vite example

A page with a 3D dice box and an input to roll any DX roll string.

The example uses the library from this repository and serves the dice meshes from `examples/meshes`.

## Running the example

1. Build the library: `npm install && npm run build` in the repository root
1. In this directory, run `npm install` followed by `npm run dev`
1. Open the printed URL, enter a roll such as `4d6kh3 + 2` and press "Roll"
